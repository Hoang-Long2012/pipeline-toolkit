# Guides

These guides introduce the main ways to build, edit, compose, and coordinate pipelines with `pipeline-toolkit`.

## Choose a Guide

- [Getting Started](getting-started.md): install the package, run a first pipeline, and inspect its result.
- [Building & Editing Pipelines](building-and-editing-pipelines.md): configure callable arguments and change pipeline steps.
- [Functional Composition & Steps](functional-composition.md): compose callables, create configured steps, and pass values between functions.
- [Side Effects & State](side-effects-and-state.md): observe values, mutate them intentionally, and inspect execution state.
- [Concurrency & Coordination](concurrency-and-coordination.md): run pipelines in worker threads, coordinate groups, and pause at checkpoints.
- [Error Handling](error-handling.md): inspect failed steps, record errors, and continue after failures.

The [API reference](../api/Pipeline.md) documents the complete public API.
